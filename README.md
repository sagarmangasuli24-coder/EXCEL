# DYNAMIC RETAIL DASHBOARD
📊 Project Overview
An interactive Excel-based retail analytics dashboard designed to provide comprehensive insights into sales performance, order trends, and geographical distribution for a retail business.
🎯 Dashboard Features
Key Performance Indicators (KPIs)

Total Sales: $1,285,452
Total Profit: $143,457
Total Quantity: 1,79,332 units
Total Orders: 5,390
Profit Margin: 11.61%

📁 Data Structure
The dashboard is built using three primary data tables:

Orders Table: Contains transaction-level data including order ID, dates, customer info, location, and product details
Returns Table: Tracks returned orders and reasons
People Table: Manages regional sales representatives and territories

🛠️ Technical Details

Platform: Microsoft Excel
Dashboard Type: Interactive, filter-enabled analytics dashboard
Visualization Types: Donut charts, ring charts, bar charts, line graphs, geographic maps
